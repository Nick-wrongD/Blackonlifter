                             GETTING STARTED
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Install Dependencies
   $ npm install

STEP 2: Configure Firebase
   1. Create .env.local file
   2. Add 6 Firebase environment variables
   3. Follow SETUP.md for detailed instructions

STEP 3: Start Development Server
   $ npm run dev
   → Opens http://localhost:3000

STEP 4: Test the Application
   - Sign up with email
   - Or sign in with Google
   - Browse 4 training modes
   - Click "Change Level" to switch modes
   - Sign out when done

STEP 5: Deploy to Production
   - Push to GitHub
   - Connect to Vercel
   - Add environment variables
   - Deploy automatically

═══════════════════════════════════════════════════════════════════════════════
                            FIREBASE SETUP TIP
═══════════════════════════════════════════════════════════════════════════════

To get your Firebase credentials:
1. Go to Firebase Console (console.firebase.google.com)
2. Create a new project or select existing
3. Enable Authentication (Email/Password + Google)
4. Copy Web SDK config from Project Settings
5. Extract 6 values into .env.local:

   NEXT_PUBLIC_FIREBASE_API_KEY=...
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=...
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
   NEXT_PUBLIC_FIREBASE_APP_ID=...

See SETUP.md for detailed instructions!
